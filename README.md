# 💸 Zorvyn Finance Dashboard - Frontend Assessment

A high-fidelity, professional Finance Dashboard built for the **Frontend Developer Intern** role at **Zorvyn FinTech**. This application demonstrates real-time state management, Role-Based Access Control (RBAC), and localized data visualization for the Indian market.

## 📦 Installation & Dependencies

To run this project locally, follow these steps:

### 1. Clone the repository
```bash
git clone https://github.com/deepthip711/zorvyn-finance-dashboard.git
cd zorvyn-finance-dashboard
````

### 2. Install dependencies

npm install

### 3. Start the application

npm start

## 📚 Core Libraries Used

* **recharts** – For responsive SVG-based data visualization
* **lucide-react** – For modern and consistent icons
* **tailwindcss** – For utility-first styling and responsive UI

---

## ✨ Key Features

### 🇮🇳 Indian Localization

* All currency values are displayed in Indian Rupees (₹)
* Uses `en-IN` locale formatting for accurate representation

### 🔐 Interactive RBAC (Role-Based Access Control)

* **Admin Mode:**

  * Add new transactions
  * Edit existing records using a custom modal

* **Viewer Mode:**

  * Read-only access
  * Actions are disabled with "Locked" indicators

### ⚡ Live State Updates

* Real-time recalculation of:

  * Net Balance
  * Total Income
  * Total Expenses

* Table and filters update instantly without page reload

### 👤 Dynamic Profile

* Editable user profile in sidebar
* Name updates globally across the dashboard

### 📱 Responsive Design

* Mobile-first approach
* Built using Tailwind CSS with Glassmorphism UI design
